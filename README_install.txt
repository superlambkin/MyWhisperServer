================================================================
 MyWhisperServer ポータブルインストーラ
================================================================
バージョン: v1.8.12 以降のポータブル版
対象: Windows 10/11 (64bit)
ポート: Dashboard 9001 / Whisper 9000 / PaddleOCR 9100

----------------------------------------------------------------
【概要】
このパッケージは GPU (CUDA) / CPU を選択してインストールできる
MyWhisperServer のポータブル版です。
- Python 環境（ランタイム）は同梱済み。
- モデルは同梱せず、インストール後に Dashboard の「モデル管理」から
  ダウンロードします。
- 依存ライブラリ（torch / paddle 等）はインストール時に選択に応じて
  ダウンロードします（インターネット接続が必要）。

----------------------------------------------------------------
【インストール手順】
1. このフォルダを好きな場所に展開します（例: C:\MyWhisperServer）。
   パスにスペースが含まれない場所を推奨します。
2. `install.bat` をダブルクリック（またはコマンドプロンプトで実行）します。
3. 指示に従い GPU (CUDA) / CPU を選択します。
   - GPU: NVIDIA ドライバが入っている環境（CUDA 11.8 / torch cu121）
   - CPU: GPU のない環境
   自動検出は `nvidia-smi` の有無で行います。
4. インストールが完了すると、デスクトップに「MyWhisperServer」の
   ショートカットが作られます。

----------------------------------------------------------------
【起動方法】
デスクトップの「MyWhisperServer」をダブルクリックします。
（または `start_server.bat` を実行）
初回はブラウザで http://localhost:9001 を開き、
「モデル管理」ページから Whisper / PaddleOCR / Kokoro のモデルを
ダウンロードしてください。モデルは `models\` に保存されます。

----------------------------------------------------------------
【GPU / CPU の違い】
- GPU: torch (cu121) + paddlepaddle-gpu 3.3.1（CUDA 11.8 ビルド、
  12.x ドライバでも動作）。高速ですが VRAM を消費します。
- CPU: torch (cpu) + paddlepaddle（PyPI）。GPU 不要ですが遅めです。

----------------------------------------------------------------
【主なポート】
- 9001: Dashboard（管理画面・ブラウザ）
- 9000: Whisper 音声認識 API
- 9100: PaddleOCR（画像 OCR / PDF→Markdown）

----------------------------------------------------------------
【アンインストール】
`uninstall.bat` を実行すると、venv / models / データベース / ログと
デスクトップのショートカットが削除されます。
（ソースファイルは残ります。完全削除はフォルダごと削除してください。）

----------------------------------------------------------------
【ライセンス・再配布】
- Python: 同梱の python-build-standalone（PSF ライセンス）
- ffmpeg: 同梱の static ビルド（BtbN/FFmpeg-Builds・GPL）
- 本アプリ本体: Apache 2.0
再配布の際は各ライセンス表記をご確認ください。

----------------------------------------------------------------
【トラブルシューティング】
- 起動できない場合: インストール時の選択（GPU/CPU）と環境が合っているか確認。
- モデル一覧が空: モデル管理ページからダウンロードしてください。
- ffmpeg エラー: runtime\ffmpeg\bin が PATH に含まれているか確認
  （start_server.bat が自動で追加します）。
