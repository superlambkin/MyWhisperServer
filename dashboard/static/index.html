朗读 TTS

                                

                                    

                                        
                                        
                                    

                                    

                                        
                                        
                                    

                                    
                                    

                                        
                                        
                                        
VibeVoice-TTS（1.5B）は英語・中国語のみ・CPU のみで合成未対応です。選択時は Realtime（0.5B）で読み上げます。

                                    

                                    
                                    

                                        
                                        
                                    

                                    
                                    

                                        

                                            
起動時にローカルTTSをVRAMに読込（常駐）

                                            
Kokoro / VibeVoice をダッシュボード起動時に読み込み、以後アンロードせず常駐させます（初回読み上げが即応答。VRAM は消費します）

                                        

                                        
                                    

                                    
本地引擎首次使用会下载模型。未安装的引擎请切换到 Edge TTS。VibeVoice 需单独安装（见 README）。
